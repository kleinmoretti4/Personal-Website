# Personal-Website
This is my personal website to showcase who I am as a person: My hobbies, skills, interest and other websites I have designed for clients.

## Inspiration
I wanted my website to be a reflection of me, to achieve that I stylised the website to look like a shelve, based on some inspirations I found on Pinterest.
